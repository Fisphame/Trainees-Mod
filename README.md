# Trainees（练习生）

> Minecraft **1.20.1** · **Forge 47.x** · 许可证 GNU GPLv3
> 仓库：<https://github.com/Fisphame/Trainees-Mod>

这个模组的核心是一套**规则驱动的化学系统**：反应由「反应规则 + 热力学 + 动力学」自己跑起来，
而不是配方查表；温度、浓度、压力、通电与否都会改变结果。

## 当前玩法概览

**化学引擎**
- 反应图 + 反应规则：每条规则带 ΔH/ΔG、活化能、指前因子、温度门槛与前置条件
- 物理平衡常数 `K = exp(−ΔG(T)/RT)`：方向由 Q vs K 自动决定，可逆反应无需手写分支
- 温度依赖：竞争反应由阿伦尼乌斯自然分化（例如"低温→次氯酸盐 / 高温→氯酸盐"）
- 失败诊断 + 反应预测器：分析仪右键容器即可看到"为什么没反应"和"原料被谁消耗了"

**容器与材料**
- 烧杯（玻璃，≤773 K）、金属坩埚（1673 K）、石英坩埚（1873 K）、陶瓷坩埚（2273 K）
- 容器材料决定耐温上限与热容——**炼钢与熔盐必须换坩埚**，这是第一道硬墙

**热源与控温**
- 燃料型热源：火 / 灵魂火 / 岩浆 / 岩浆块 / 营火（只能单向烤热）
- 设定点型热源：**恒温浴**（冰盐浴 ≤0 ℃、水浴 ≤100 ℃、油浴 ≤250 ℃、沙浴 ≤600 ℃，介质决定区间）
- **创造热源**：可把目标温度设为任意值（含 0 ℃ 以下），用于测试与教学

**相变**
- 水的三相（冰 / 水 / 蒸汽）与食盐固液：熔点、沸点、潜热全部由热力学决定
- 熔化时温度会"卡"在熔点（相变平台），敞口煮沸的蒸气会进入气体网格

**电解**
- 电解槽：双电极接入面、双面供电、离子交换膜产物分侧、1~5 档工作电压（档位影响电耗与净热账）
- 熔盐电解：先把食盐熔化到 1074 K 以上，电解吸热会让它冻回去——需要持续供热

**日化品与打包机**
- **打包机**：读取其正上方容器里的溶液，按**规格**质检后灌装（标准驱动，不产生新化学）
- 含氯消毒液：**有效氯**合格 5.0–8.0%、优质 6.0–7.5%；门禁 游离氯禁用 / 游离酸 ≤0.05% / 游离碱 ≤1% / 氯酸盐 ≤1%
  （有效氯按国标口径折算：1 mol ClO⁻ ≡ 1 mol Cl₂，图鉴里写了这个概念）
- **打包机自驱**：通电、溶液合格、输出槽有空位时自动打瓶（永远 auto 模式，不合格**不产出也不扣料**）
- **FE 门槛**：每瓶默认 20 kJ（1 FE = 1 J，可配置）；任意面都可通过 `IEnergyStorage` 充能
- **输出槽**是 `IItemHandler`（外部只能抽）：AE2 输出总线 / 漏斗 / 管道可直接取货，**槽满自动停产**
- 交互：**空手右键取走产物**；**潜行空手右键 = 人工强制灌装**（唯一能产危险次品的入口）
- **次品会反噬**：游离氯 → 中毒、碱超标 → 化学烧伤、酸超标 → 自毁放气、氯酸盐超标 → 中毒
- **浓度不符不产次品**：次品只为"危险批次"存在；浓度不达标（过低/过高）时任何模式都不灌装

## 安装

1. 安装 **Forge 47.x for 1.20.1**
2. 把 `trainees-<version>.jar` 放进 `mods/`
3. 可选模组：**JEI**（图鉴与反应查询）、**AE2**（汲取方块主动推送）、**Configured**（自动生成配置界面）

## 开发者

```bash
./gradlew build        # 出包 → build/libs/
./gradlew runClient    # 开发客户端
./gradlew runServer    # 专用服务器
./gradlew test         # 单元测试（化学/规格/相变/材料/打包判定）
./gradlew runData      # 数据生成（forge 公共标签）
```

- **开发蓝本**（全部设计决策与踩坑记录）：`src/main/java/com/pha/trainees/trainees开发蓝本.txt`
- **更新日志**：`CHANGELOG.md` —— 注意根目录的 `changelog.txt` 是 **Forge 自带的**，与本模组无关
- **缺失资源清单**：`RESOURCES_MISSING.md`
- 调试命令：`/chemtester add|info|heat|power|gas|fluid|graph|last|failures`（需权限等级 2）
